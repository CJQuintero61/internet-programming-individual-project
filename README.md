# internet-programming-individual-project

This repo contains all related files for my individual project for my internet programming class in Fall 2026.
This project is a Valorant agent viewer where you select an agent from the game and can read about their
description and abilities and see what they look like.

The project is meant to be simple and small in scope and only use HTML, CSS, and JS with no additional frameworks.

## To Run

1. [Clone the repo from this link](https://github.com/CJQuintero61/internet-programming-individual-project)
2. [Install the Live Server extension in VSC](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer)
3. Right click on `index.html` and click "open with live server" or click "go live" in the bottom right of your VSC window
4. Use the webpage in the browser tab that was opened by the live server
